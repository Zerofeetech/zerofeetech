# ZeroFeeTech — clean Flask starter

A responsive, free-first digital studio starter with account registration, login, user workspace, project enquiries, admin dashboard and a local prompt builder.

## Deploy on Render
1. Upload the contents of this folder to the root of a clean GitHub repository (so `app.py`, `requirements.txt`, `render.yaml`, `templates/` and `static/` are at repository root).
2. Create or update the Render Web Service to use that repository.
3. Set **Root Directory** to blank (repository root).
4. Build command: `pip install -r requirements.txt`
5. Start command: `gunicorn app:app --bind 0.0.0.0:$PORT`
6. Set `ADMIN_PASSWORD` in Render Environment to a strong private password. Keep `ADMIN_EMAIL` as `admin@zerofeetech.com`.
7. Keep `SECRET_KEY` generated by Render. Do not publish passwords or secret values in GitHub.

## Important limitations
- The prompt builder creates reusable prompts; it is not connected to a paid or free AI model.
- Contact requests are saved in the admin dashboard. Email notifications are not configured.
- Render free instances may not provide durable local disk storage. For persistent accounts and enquiries, attach a persistent disk or use a supported external database before relying on production data.
- This starter has not been deployed to your Render account. Test the deployment and the main flows before announcing it as live.
